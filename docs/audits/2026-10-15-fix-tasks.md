# Final-audit remediation tasks

Scope: A1–A6 in the final release audit. Keep existing components and response shapes;
no release publication, broad rewrite or new virtualization framework.

1. A1 — platform boundary
   - Declare macOS 14.0 minimum in bundle metadata.
   - Guard that minimum in release configuration checks.
   - Document WebView requirements and keep minimum-device acceptance pending.
2. A2 — instance artwork
   - Decode PNG/JPEG/WebP with file, dimensions and allocation limits.
   - Produce 128-pixel PNG derivatives; preserve original files.
   - Reuse the bounded thumbnail disk cache and serialize image work.
   - Bound total response bytes/count; retain the existing missing-icon fallback when a derivative is absent.
   - Test valid padded images, hostile dimensions, formats, cache reuse and aggregate limits.
3. A3 — native responsiveness
   - Put filesystem/configuration mutations and reads behind async blocking workers.
   - Preserve validation, atomic settings saves, errors and Tokio launch context.
   - Leave native dialog ownership and cheap in-memory operations unchanged.
4. A4 — bounded collections
   - Reuse 24-item pages and Pagination for full resource/content views.
   - Limit shelves to 24 items with View all for the complete filtered collection.
   - Reset on query/category changes; clamp after mutations.
   - Select deep-link pages before focus; replace repeated owner/folder searches with maps.
   - Test complete search, last pages, clamping and off-page world/server navigation.
5. A5 — loader accessibility
   - Give async errors alert semantics and stable field association.
   - Keep Retry/focus behavior; test the failed-request and recovery path.
6. A6 — release guidance
   - Correct bundled Microsoft client setup and development-only override guidance.
   - Update appearance, languages, labels, settings guards and platform policy.
   - Include Arabic/RTL, minimum-WebView and screen-reader acceptance scenarios.
7. Verification and handoff
   - Run focused tests, then the existing complete audit/candidate SOP.
   - Push fixes and run cross-platform CI; record actual results and limits.
   - Pause at human/device verification; do not tag or publish a release.
