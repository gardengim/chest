# Before subtle face lighting

These are the unmodified Chest mark and macOS icon SVGs saved before the 2026-10-16 revision.

The current mark is generated by `scripts/chest-mark.mjs`. Run `npm run icons` to reproduce `public/chest.svg` and desktop assets. The six vertices come from a radius-52 regular hexagon centered at (64, 64), spaced by 60 degrees. The latch follows 30-degree isometric axes. SVG output is static and needs no runtime script.

Changes: subtle top highlight, right-face shade, silver latch highlight and halo. Left face, outer dimensions, 7-unit outline and latch placement are preserved. See `docs/design/chest-icon-comparison.html` or its PNG for before/after views.
